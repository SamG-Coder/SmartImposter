# Quixel assets to download for the whole Earth

Free Quixel (Megascans / Megaplants) only. Each name links to a Fab search. On Fab: **Add to My Library** (free), then download it the same way as the assets already in the project:

- **Megaplants (trees):** through the Fab plugin in Unreal. `tools/ue_export_megaplants.py` exports them.
- **3D plants and grasses:** as glTF.
- **Surfaces:** into your Fab library folder (`SI_GROUND_DIR`).

Groups 1–4 cover most of the land area; do those first. Where a search shows several variants, take the one marked Quixel / Megascans.
Already in the project (skip): European Beech, Black Alder, Black Poplar, European Aspen, Common Hazel, Bracken Fern, Heather, Huckleberry Oak, the 7 grasses, and the 15 current ground scans.
